## Незаметные вычисления

Пусть в процессе создаются нити с tid-ами `A` и `B` соответственно.

Гарантируются атомарность операций, отсутствие буферизации и успешные системные вызовы. Написать все возможные выводы процесса с множеством нитей.

```c
int counter = 0;

void func(void* arg) {
	int a = *(int*) arg;

	counter += a;
	printf("%ld:%d\n", pthread_self(), counter());
	pthread_exit(NULL);
}

int main(void) {
	pthread_t t1, t2;
	int a = 2, b = 3;

	pthread_create(&t1, NULL, func, &a); // A
	pthread_create(&t2, NULL, func, &b); // B

	pthread_join(t1, NULL);
	pthread_join(t2, NULL);

	return 0;
}
```

## Быстросчет свободных блоков

В системе используется схема учета свободных блоков через МНСБ. Сколько блоков хранят массив, если система имеет следующие параметры:

 + Размер блока 1024 байта, размер указателя на блоки 4 байта, всего блоков в системе 2^20
 + Размер блока 512 байт, размер указателя на блоки 64 байта, всего блоков в системе 123456789
 + Размер блока 2048 байт, размер указателя на блоки 4 байта, объем памяти 128 Гб
 + Размер блока 128 байт, размер указателя на блоки 8 байт, объем памяти 2Тб

## Быстросчет обменов

В систему, использующую схему связного размещения блоков в памяти, поступил запрос на чтение текстового файла в некотором диапазоне `D` (отрезок, полуинтервал, интервал). Размер блока ФС равен `N`, размер ссылки на следующий блок файла равен `M`. Нумерация байтов в файле начинается с `K`. Какое минимальное количество обменов необходимо для получения данных из памяти при следующих значениях параметров:

 + D = \[1234, 5678\], N = 1024, M = 4, K = 1
 + D = \(3073, 8200\], N = 2060, M = 10, K = 0
 + D = \[8675, 9876\), N = 512, M = 8, K = 1
 + D = {\(1234, 5678\), \[7800, 9600\]}, N = 128, M = 1, K = 0

## Битов много не бывает

В системе используется схема контроля блоков на базе битовых массивов. Размер ФС `V type`. Размер блока `N` байт. Сколько `type2` занимает битовый массив, описывающий блоки системы при следующих значениях параметров
