## Странный калькулятор

Напишите программу, которая принимает с входного потока матрицу целых чисел (int) 3х3 и возвращает её детерминант. Основной процесс должен выполнять только операции суммирования. На вычисление каждого произведения заводится отдельный процесс (итого 6 сыновьих процессов). Передача данных между процессами (множители в одну сторону, произведение в другую) осуществляются через неименованные каналы. В програме необходимо корректно обработать **все** системные вызовы.

```console

4 -2 5
2 8 7
```

```console
-306
```

# Задачи на файловые системы

## Фрагментация мать её

Пусть система работает по принципу непрерывного размещения данных в памяти. Контроль размещения файлов определяется таблицей описания файлов.

Доступ к памяти обеспечивается через указатель на память типа `FILE* memory`, размер памяти равен `N` (задан отдельным макросом, писать его самостоятельно не нужно). Таблица описания файлов описывается следующим образом:

```c
struct table {
	char[20] name;
	unsigned start_pos;
	unsigned length;
};

struct table[K] files;
```

`K` задан отдельным макросом; гарантируется, что больше K записей в тестах не придет.

В систему поступают запросы вида:
 + `+ <Имя_файла_одним_словом> <Данные_файла_одним_словом>` — создание файла с такими данными
 + `* <Имя_файла_одним_словом> <Данные_файла_одним_словом>` — дописывание данных в конец существующего файла
 + `- <Имя_файла_одним_словом>` — удаление файла

Напишите функцию `int memory_control(FILE* memory, struct table* files, char* response)` которая реализует работу с памятью согласно запросам.
 + При возможности добавляет новые файлы в память; при невозможности возвращает `ENOSPACE` без изменения памяти
 + При возможности дописывает файл на месте; иначе ищет новое место размещения дополненного файла; при невозможности возвращает `ENOUPD` без изменения памяти
 + При существовании файла удаляет его по запросу; при отсутствии оного возвращает `ENOFILE` без изменения памяти

## МНСБ — Мне надо следить за блоками

Пусть в системе используется схема выдачи свободных блоков на базе массива номеров свободных блоков. Размер блока `N`, размер записи void* (то есть количество записей в одном блоке  определяется формулой `N / sizeof(void*)`). Доступ к МНСБ осуществляется по указателю типа `void** mnsb`

Напишите функцию `void* give_free_block(void*** mnsb_superblock_place)`, которая реализует работу с МНСБ:
 + При запросе выдает указатель на свободный блок;
 + При отсутствии свободных блоков возвращает `NULL`;

_Условия_:
 + схема выбора указателя свободного блока не регламентируется ничем кроме _ограничения на скорейшую выдачу указателя_ (если из первого блока можно получить адрес без перехода ко второму, надо брать из первого)
 + указатель на массив в суперблоке должен оставаться валидным

## Больше блоков богу блоков

Пусть в системе для отслеживания блоков файла используется массив номеров блоков файла классического размера. Размер номера `unsigned`, размер блока ФС `N`. Доступ к массиву осуществляется через указатель `unsigned* mabf`, получение указателя на блок ФС по его номеру осуществляется функцией `unsigned* give_block(unsigned num)`, номер `0` означает конец массива (за блок не считается).

Написать функцию `long long file_block_size(unsigned* mabf)`, которая реализует работу с МАБФ:
 + Возвращает размер файла в блоках
 + При ошибках доступа возвращает `EINVALID`
