# Хэш-таблица страниц

Размер страницы равен 256 байтам. Хэш-таблица страниц содержит 4 bucket, а хэш-функция имеет вид `hash(vp) = vp % 4`, где `vp` — номер виртуальной страницы. Коллизии разрешаются односвязными цепочками. Каждая новая запись вставляется в начало цепочки соответствующего bucket.

Для каждого виртуального адреса требуется найти запись в цепочке bucket, вычисленного по его номеру виртуальной страницы. Если записи нет или она помечена как отсутствующая в памяти (`present = 0`), необходимо вывести `PAGE_FAULT`. Иначе нужно сформировать физический адрес и вывести его в шестнадцатеричной системе.

## Принцип алгоритма

1. Сохранить записи в массиве. Для каждой записи добавить её индекс в начало цепочки bucket `vp % 4`.
2. Для виртуального адреса `VA` вычислить `vp = VA / 256` и `offset = VA % 256`.
3. Пройти по цепочке bucket `vp % 4`, сравнивая номера виртуальных страниц.
4. При отсутствии записи или при `present = 0` вывести `PAGE_FAULT`. Иначе вычислить `PA = frame * 256 + offset`.

Например, записи с `vp = 0` и `vp = 4` попадают в bucket 0. После вставки записи `4 2 1` в начало цепочки она имеет вид `vp 4 -> vp 0`; поиск должен пройти по этой цепочке.

## Формат ввода

Первая строка содержит целое число `n` (`0 <= n <= 128`) — количество записей.

В следующих `n` строках находятся записи вида:

```
vp frame present
```

Здесь `vp` — номер виртуальной страницы, `frame` — номер физического кадра, `present` — признак присутствия страницы в памяти.

Затем задаётся целое число `q` (`0 <= q <= 128`) — количество запросов, после которого следуют `q` виртуальных адресов в шестнадцатеричной системе. Адреса могут быть записаны с префиксом `0x`.

## Формат вывода

Для каждого запроса вывести отдельную строку: физический адрес в формате `0x%x` либо `PAGE_FAULT`.

## Пример

Ввод:

```
3
0 5 1
4 2 1
1 7 1
4
0x0401 0x0002 0x0103 0x0200
```

Ожидаемый вывод:

```
0x201
0x502
0x703
PAGE_FAULT
```

Для `0x0401` страница `vp = 4` находится в bucket 0 после коллизии с `vp = 0`, поэтому физический адрес равен `2 * 256 + 1 = 0x201`. Страница `vp = 2` отсутствует в таблице, поэтому последний запрос приводит к страничному отказу.
