# Инвертированная таблица страниц

В системе используется **одна общая инвертированная таблица страниц** для всех процессов. Размер страницы и физического кадра равен 256 байтам. Таблица содержит по одной записи на каждый физический кадр; индекс записи является номером этого кадра.

Каждая запись имеет вид `pid vp valid`:

- `pid` — идентификатор процесса;
- `vp` — номер виртуальной страницы;
- `valid` — признак действительности записи (`1` — действительна, `0` — свободна или недействительна).

Для запроса заданы `pid` и виртуальный адрес `VA`. Требуется найти действительную запись с такой же парой `(pid, vp)`, где `vp = VA / 256`. Если запись найдена, номер её строки считается номером физического кадра, и физический адрес вычисляется по формуле:

```text
PA = frame * 256 + VA % 256
```

Если подходящей записи нет, требуется сообщить об отсутствии страницы.

PID является частью ключа поиска, потому что одинаковые номера виртуальных страниц у разных процессов обозначают разные страницы. Единая таблица описывает физические кадры всей системы, а не отдельное виртуальное адресное пространство одного процесса.

## Алгоритм

1. Сохранить все записи инвертированной таблицы в массив.
2. Для каждого запроса выделить из виртуального адреса номер страницы `vp` и смещение `offset`.
3. Линейно просмотреть таблицу, сравнивая `pid` и `vp` только у записей с `valid = 1`.
4. При совпадении вывести физический адрес, используя индекс найденной записи; иначе вывести `PAGE_FAULT`.

## Формат ввода

Первая строка содержит целое число `frames` (`1 <= frames <= 128`) — количество физических кадров и записей таблицы.

Следующие `frames` строк содержат по три целых числа:

```text
pid vp valid
```

Поля `pid` и `vp` читаются для каждой записи, в том числе при `valid = 0`.

Затем задаётся целое число `q` — количество запросов. Каждая из следующих `q` строк содержит идентификатор процесса `pid` и виртуальный адрес `VA` в шестнадцатеричной системе с префиксом `0x`.

## Формат вывода

Для каждого запроса вывести на отдельной строке физический адрес в шестнадцатеричной системе с префиксом `0x` либо `PAGE_FAULT`, если действительная запись с нужными `pid` и `vp` отсутствует.

## Пример

Ввод:

```text
4
7 0 1
7 1 1
8 0 1
0 0 0
4
7 0x0010
7 0x0101
8 0x0002
8 0x0100
```

Вывод:

```text
0x10
0x101
0x202
PAGE_FAULT
```
