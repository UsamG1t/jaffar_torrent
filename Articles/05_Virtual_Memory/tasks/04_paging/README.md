# Одноуровневое страничное распределение

Дана одноуровневая таблица страниц. Размер страницы равен 256 байтам. Каждая запись связывает номер виртуальной страницы `vp` с номером физического кадра `frame` и содержит бит присутствия `present`.

Требуется для каждого виртуального адреса определить физический адрес или сообщить об отсутствии страницы в памяти.

## Принцип алгоритма

Для виртуального адреса `VA` вычисляются:

- номер виртуальной страницы: `vp = VA / 256`;
- смещение внутри страницы: `offset = VA % 256`.

Затем выполняется линейный поиск записи с таким `vp`. Если записи нет или её бит `present` равен нулю, происходит страничная ошибка. Иначе физический адрес равен `frame * 256 + offset`.

Номер виртуальной страницы и номер физического кадра — разные величины: физический адрес строится именно из `frame`. При переходе от виртуального адреса к физическому смещение `offset` сохраняется без изменений.

## Формат ввода

Первая строка содержит целое число `n` (`0 <= n <= 128`) — количество записей таблицы страниц.

Далее следуют `n` строк в формате:

```
vp frame present
```

`vp` и `frame` — беззнаковые номера виртуальной страницы и физического кадра, `present` равен `0` или `1`.

Следующая строка содержит число `q` — количество запросов. Далее следуют `q` виртуальных адресов в шестнадцатеричной записи.

## Формат вывода

Для каждого запроса выводится отдельная строка:

- `PAGE_FAULT`, если запись не найдена или страница отсутствует в памяти;
- физический адрес в формате `0x%x`, если преобразование выполнено успешно.

## Пример

Ввод:

```
3
0 5 1
1 2 0
2 7 1
5
0x0000
0x00ff
0x0100
0x0204
0x0300
```

Ожидаемый вывод:

```
0x500
0x5ff
PAGE_FAULT
0x704
PAGE_FAULT
```
