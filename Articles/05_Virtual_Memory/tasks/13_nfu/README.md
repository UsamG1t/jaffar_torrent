# NFU — выбор страницы по накопленной истории

## Условие

Есть `n` резидентных страниц с номерами от `0` до `n - 1`, где `1 <= n <= 128`. Для каждой страницы хранятся бит обращения `R` и счётчик `counter`. Изначально все биты и счётчики равны нулю.

Программа обрабатывает команды:

- `R p` — отметить обращение к странице `p`: установить её бит `R` в `1`;
- `T` — завершить текущий интервал: для каждой страницы выполнить `counter += R`, после чего сбросить её бит `R` в `0`;
- `E` — выбрать страницу с минимальным значением `counter`. Если таких страниц несколько, выбрать страницу с минимальным номером, вывести результат и завершить работу.

## Принцип алгоритма

NFU (Not Frequently Used) оценивает частоту обращений по накопленной истории. Бит `R` показывает только наличие обращения в текущем интервале, поэтому повторные команды `R p` до ближайшего `T` не увеличивают счётчик несколько раз. Счётчики изменяются лишь в конце интервала командой `T`; одновременно биты обращения подготавливаются к следующему интервалу.

Для выбора жертвы достаточно один раз просмотреть массив счётчиков. Строгое сравнение при просмотре по возрастанию номеров сохраняет первую страницу при равенстве счётчиков.

## Формат ввода

Первая строка содержит целое число `n`. Далее идут команды `R p`, `T` и `E` в описанном выше формате. Команда `E` присутствует и является последней обрабатываемой командой.

## Формат вывода

По команде `E` вывести одну строку:

```
EVICT p counter c
```

Здесь `p` — номер выбранной страницы, а `c` — её счётчик.

## Пример

Ввод:

```
4
R 0
T
R 0
T
R 1
R 2
R 3
T
E
```

Вывод:

```
EVICT 1 counter 1
```

После трёх интервалов счётчики страниц `0, 1, 2, 3` равны соответственно `2, 1, 1, 1`. Минимальный счётчик имеют страницы `1`, `2` и `3`; из них выбирается страница с наименьшим номером `1`.
