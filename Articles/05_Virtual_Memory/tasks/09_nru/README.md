# Замещение страниц по алгоритму NRU

В памяти находятся `n` страниц с номерами от `0` до `n - 1` (`1 <= n <= 128`). Для каждой страницы хранятся бит обращения `R` и бит изменения `M`. Изначально для всех страниц `R = M = 0`.

Программа обрабатывает команды обращения к страницам и периодического сброса битов обращения. По команде `E` нужно выбрать жертву по алгоритму NRU (Not Recently Used) и завершить работу.

Класс страницы вычисляется по формуле `c = 2 * R + M`:

| Класс | R | M | Описание |
|:---:|:---:|:---:|---|
| 0 | 0 | 0 | Обращения не было, страница не изменялась |
| 1 | 0 | 1 | Обращения не было, страница изменялась |
| 2 | 1 | 0 | Обращение было, страница не изменялась |
| 3 | 1 | 1 | Обращение было, страница изменялась |

Жертвой становится страница из непустого класса с минимальным номером. Если в этом классе несколько страниц, выбирается страница с минимальным номером.

## Принцип решения

Биты `R` и `M` хранятся в двух массивах, индексами которых являются номера страниц. Чтение устанавливает `R = 1`, а запись — `R = 1` и `M = 1`. Команда `T` обнуляет только биты `R`; биты `M` сохраняются.

При выборе жертвы страницы просматриваются в порядке возрастания номеров. Запоминается страница с наименьшим классом; при равенстве классов ранее найденная страница не заменяется, поэтому сохраняется минимальный номер.

## Формат ввода

Первая строка содержит целое число `n`. Далее до конца ввода записаны команды, по одной в строке:

- `R p` — чтение страницы `p`: установить `R[p] = 1`;
- `W p` — запись страницы `p`: установить `R[p] = 1` и `M[p] = 1`;
- `T` — обнулить `R` у всех страниц, не изменяя `M`;
- `E` — выбрать жертву, вывести результат и завершить программу.

Номер `p` находится в диапазоне от `0` до `n - 1`. Команда `E` встречается ровно один раз.

## Формат вывода

Единственная строка:

```text
EVICT p class c
```

Здесь `p` — номер выбранной страницы, а `c` — её класс в момент выполнения команды `E`.

## Пример

Ввод:

```text
4
W 0
W 1
R 2
W 3
T
R 2
W 3
E
```

Вывод:

```text
EVICT 0 class 1
```

До команды `T` страницы 0, 1 и 3 изменялись, поэтому после сброса `R` их биты `M` сохраняются: классы страниц становятся равны `1, 1, 0, 1`. После повторных обращений к страницам 2 и 3 в момент `E` классы равны `1, 1, 2, 3`. Минимальный непустой класс — 1, а минимальный номер страницы в нём — 0.
