# Сегментно-страничная адресация

Смоделируйте преобразование виртуального адреса в физический в упрощённой модели классического 32-битного x86. Размер страницы равен 4096 байтам.

Виртуальный адрес задаётся парой `selector offset`. У селектора используются следующие поля:

- `index = selector >> 3` — номер дескриптора;
- `TI = (selector >> 2) & 1` — таблица дескрипторов: `0` означает GDT, `1` — LDT;
- биты RPL игнорируются.

Присутствуют только два дескриптора:

| Таблица | Индекс | Базовый адрес | Лимит |
|---|---:|---:|---:|
| GDT | 1 | `0x00000000` | `0x0000ffff` |
| LDT | 1 | `0x00010000` | `0x0000ffff` |

Все остальные дескрипторы отсутствуют. Если дескриптор отсутствует или `offset > limit`, необходимо вывести `SEGMENT_FAULT`. Иначе линейный адрес вычисляется как `linear = base + offset`.

Для страничного преобразования используется единый page directory: запись с индексом `0` содержит номер page table `0`, остальные записи отсутствуют. В page table `0` присутствуют только следующие записи:

| Индекс страницы | Номер фрейма |
|---:|---:|
| 0 | 5 |
| 1 | 7 |
| 16 | 9 |

Линейный адрес разбивается на поля:

```text
dir            = (linear >> 22) & 0x3ff
table          = (linear >> 12) & 0x3ff
offset_in_page = linear & 0xfff
```

Если запись page directory или page table отсутствует, выведите `PAGE_FAULT`. При успешном преобразовании физический адрес равен `(frame << 12) | offset_in_page`.

Таким образом, преобразование выполняется последовательно: сначала селектор и смещение проверяются по сегментному дескриптору и образуют линейный адрес, затем линейный адрес проходит двухуровневое страничное преобразование.

## Формат ввода

Первая строка содержит целое число `q` — количество запросов. В каждой из следующих `q` строк записаны два шестнадцатеричных числа: `selector` и `offset`.

## Формат вывода

Для каждого запроса выведите одну строку: физический адрес в формате `0x%x`, либо `SEGMENT_FAULT`, либо `PAGE_FAULT`.

## Пример

Ввод:

```text
4
0x0008 0x00001004
0x000d 0x00000020
0x0008 0x00010000
0x0008 0x00002000
```

Вывод:

```text
0x7004
0x9020
SEGMENT_FAULT
PAGE_FAULT
```
