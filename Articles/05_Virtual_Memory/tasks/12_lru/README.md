# LRU с битовой матрицей

## Условие

В памяти есть `capacity` кадров, изначально все они свободны. Требуется обработать последовательность обращений к страницам по алгоритму LRU, используя битовую матрицу размером `capacity × capacity`.

При обращении к странице в кадре `i` сначала все биты строки `i` устанавливаются в 1, а затем все биты столбца `i` обнуляются. Таким образом, диагональный элемент также равен 0.

При промахе страница загружается в свободный кадр. Если свободных кадров нет, жертвой становится занятый кадр, строка которого имеет минимальное двоичное значение; при равенстве значений выбирается кадр с минимальным индексом. Бит столбца `j` имеет вес `2^j`. Меньшее значение строки соответствует более давнему обращению: последующие обращения к другим кадрам обнуляют соответствующие биты этой строки.

Перед загрузкой страницы в ранее использованный кадр нужно полностью очистить его строку и столбец, а затем выполнить обычное обновление матрицы для обращения к этому кадру.

## Формат ввода

Сначала задаются целые числа `capacity` и `n` (`1 <= capacity <= 16`, `0 <= n <= 1000`), затем — `n` неотрицательных целых идентификаторов страниц. Числа разделяются произвольными пробельными символами.

## Формат вывода

Для каждого обращения выводится одна строка:

- `<page> HIT` — страница уже находится в памяти;
- `<page> FAULT` — произошёл промах, свободный кадр был доступен;
- `<page> FAULT evict <victim>` — произошёл промах с вытеснением страницы `<victim>`.

После обработки всех обращений выводится строка `FAULTS <count>`, где `<count>` — общее число промахов.

## Пример

Ввод:

```text
3 6
1 2 3 1 4 2
```

Вывод:

```text
1 FAULT
2 FAULT
3 FAULT
1 HIT
4 FAULT evict 2
2 FAULT evict 3
FAULTS 5
```
