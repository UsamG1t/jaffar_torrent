# Одиночное непрерывное распределение

Операционная система занимает нижнюю часть памяти, а один пользовательский процесс располагается непосредственно после неё. Значение `os_size` хранится в **регистре границы**: оно задаёт первый адрес пользовательской области и разделяет память ОС и процесса.

Для каждого абсолютного адреса определите, какой области он принадлежит:

- адрес меньше `os_size` — область ОС;
- адрес не меньше `os_size` и меньше `memory_size` — область пользовательского процесса;
- адрес не меньше `memory_size` — вне физической памяти.

## Принцип алгоритма

Прочитайте границы памяти и последовательно сравните каждый адрес сначала с `os_size`, затем с `memory_size`. Дополнительные массивы не требуются.

## Формат ввода

Первая строка содержит три беззнаковых десятичных числа: `os_size memory_size n`, где `os_size <= memory_size`, а `n` — количество проверяемых адресов. Далее следуют `n` беззнаковых десятичных абсолютных адресов, разделённых пробельными символами.

## Формат вывода

Для каждого адреса выведите отдельную строку: `OS`, `USER` или `OUT_OF_RANGE` соответственно.

## Пример

Ввод:

```text
1024 8192 6
0 1023 1024 4095 8191 8192
```

Ожидаемый вывод:

```text
OS
OS
USER
USER
USER
OUT_OF_RANGE
```
