# Замещение страниц по алгоритму FIFO

В памяти имеется `capacity` кадров, изначально все они пусты. Программа последовательно обрабатывает обращения к страницам и моделирует замещение страниц по алгоритму FIFO.

Для каждого обращения необходимо вывести результат:

- если страница уже находится в кадре: `<page> HIT`;
- если страницы нет и есть свободный кадр: `<page> FAULT`;
- если страницы нет и все кадры заняты: `<page> FAULT evict <victim>`, где `<victim>` — номер выгруженной страницы.

При замещении выгружается страница, загруженная раньше всех остальных. Попадание не меняет порядок страниц в очереди. После обработки всех обращений нужно вывести `FAULTS <count>`, где `<count>` — общее число промахов.

## Принцип решения

Номера страниц хранятся в массиве кадров. Пока есть свободные кадры, новые страницы добавляются последовательно. После заполнения памяти массив используется как кольцевая очередь: индекс `next` указывает на кадр со страницей, которая будет выгружена следующей. После замещения индекс циклически сдвигается. При попадании выполняется только поиск страницы, индекс `next` не изменяется.

## Формат ввода

Первая строка содержит два целых числа: `capacity` (`1 <= capacity <= 16`) и `n` (`0 <= n <= 1000`) — число кадров и число обращений.

Во второй строке записаны `n` целых чисел от `0` до `127` — номера запрашиваемых страниц. Числа могут быть разделены произвольными пробельными символами.

## Формат вывода

Для каждого обращения выводится отдельная строка в указанном выше формате. В последней строке выводится общее число промахов.

## Пример

Ввод:

```text
3 6
1 2 3 1 4 2
```

Вывод:

```text
1 FAULT
2 FAULT
3 FAULT
1 HIT
4 FAULT evict 1
2 HIT
FAULTS 4
```
