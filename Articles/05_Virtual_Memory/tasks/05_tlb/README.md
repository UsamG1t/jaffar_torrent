# TLB с замещением FIFO

TLB (Translation Lookaside Buffer) — небольшой кэш записей таблицы страниц. Размер страницы равен 256 байтам, поэтому для виртуального адреса `VA` номер виртуальной страницы равен `VA / 256`, а смещение — `VA % 256`.

TLB вмещает `capacity` записей и изначально пуст. Для каждого виртуального адреса необходимо:

- при наличии его виртуальной страницы в TLB вывести `HIT` и физический адрес;
- иначе найти страницу в таблице страниц;
- если записи нет или она помечена как отсутствующая (`present = 0`), вывести `PAGE_FAULT`;
- при успешном обращении к таблице загрузить запись в TLB, вывести `MISS` и физический адрес.

Физический адрес вычисляется как `frame * 256 + offset`.

## Принцип алгоритма

Для каждой загруженной в TLB записи сохраняется время её загрузки. Если свободного места нет, вытесняется запись с минимальным временем загрузки, то есть самая старая. Попадание в TLB **не обновляет** это время и не меняет FIFO-порядок. Ошибка страницы также не изменяет TLB.

## Формат ввода

Первая строка содержит целые числа `capacity` и `n`:

- `1 <= capacity <= 16` — ёмкость TLB;
- `0 <= n <= 128` — количество записей таблицы страниц.

Следующие `n` строк содержат по три целых числа:

```text
vp frame present
```

Здесь `vp` — номер виртуальной страницы, `frame` — номер физического кадра, `present` — признак присутствия страницы в памяти (`0` означает отсутствие).

Затем задаётся число `q`, после которого следуют `q` виртуальных адресов в шестнадцатеричной записи. Адреса могут быть разделены пробелами или переводами строк.

## Формат вывода

Для каждого виртуального адреса выводится одна строка:

```text
HIT 0x<physical_address>
MISS 0x<physical_address>
PAGE_FAULT
```

Физический адрес выводится строчными шестнадцатеричными цифрами без ведущих нулей.

## Пример

### Ввод

```text
2 3
0 4 1
1 7 1
2 9 1
5
0x0010
0x0100
0x0020
0x0200
0x0030
```

### Вывод

```text
MISS 0x410
MISS 0x700
HIT 0x420
MISS 0x900
MISS 0x430
```

После первых двух промахов в TLB находятся VP0 и VP1; попадание по адресу `0x0020` не меняет их возраст. При обращении к VP2 вытесняется **VP0**, как самая старая запись. Последнее обращение к VP0 вызывает промах и вытесняет **VP1**, после чего новая запись VP0 даёт физический адрес `0x430`.
