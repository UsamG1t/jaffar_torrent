# Алгоритм «Часы»

Реализуйте замещение страниц по алгоритму «Часы» (second chance). Память содержит `capacity` кадров, изначально все кадры пусты. Для каждой страницы в последовательности обращений нужно вывести результат её обработки.

## Принцип алгоритма

У каждой занятой страницы есть бит обращения `R`. При попадании (`HIT`) установите `R = 1` у найденной страницы.

При промахе (`FAULT`):

1. Если есть свободный кадр, поместите страницу в первый такой кадр и установите `R = 1`. Указатель `hand` при этом не изменяется.
2. Если свободных кадров нет, просматривайте кадры по кругу, начиная с текущего положения `hand`:
   - если `R = 1`, сбросьте его в `0` и передвиньте `hand` на следующий кадр;
   - если `R = 0`, замените эту страницу новой, установите у новой страницы `R = 1` и передвиньте `hand` на следующий кадр.

Начальное значение `hand` — кадр с индексом `0`. Положение указателя сохраняется между обращениями.

В отличие от FIFO, алгоритм «Часы» учитывает не только порядок загрузки страниц. Бит `R` даёт недавно использованной странице второй шанс: при первом проходе указатель лишь сбрасывает её бит, а не вытесняет её сразу.

## Формат ввода

Первая строка содержит два целых числа: `capacity` (`1 <= capacity <= 16`) и `n` (`0 <= n <= 1000`). Во второй строке записаны `n` номеров страниц, каждый в диапазоне от `0` до `127`.

## Формат вывода

Для каждого обращения выведите одну строку:

- `<page> HIT` — страница уже находится в памяти;
- `<page> FAULT` — произошёл промах, страница помещена в свободный кадр;
- `<page> FAULT evict <victim>` — произошёл промах с вытеснением страницы `victim`.

После обработки всех обращений выведите `FAULTS <count>`, где `<count>` — общее число промахов.

## Пример

Ввод:

```text
3 6
1 2 3 1 4 2
```

Ожидаемый вывод:

```text
1 FAULT
2 FAULT
3 FAULT
1 HIT
4 FAULT evict 1
2 HIT
FAULTS 4
```
