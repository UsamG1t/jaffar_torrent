# Перемещаемые разделы и уплотнение

Память разделена на последовательные разделы переменного размера. Идентификатор `HOLE` обозначает свободный раздел, любой другой идентификатор — раздел, занятый процессом. Требуется разместить новый процесс, при необходимости переместив занятые разделы.

## Алгоритм

1. Найти первый свободный раздел, размер которого не меньше размера нового процесса. Если такой раздел есть, разместить процесс в нём. Неиспользованный остаток оставить сразу после процесса как раздел `HOLE`.
2. Если подходящего отдельного раздела нет, но суммарного объёма свободной памяти достаточно, выполнить уплотнение: последовательно переместить все занятые разделы к началу памяти, сохранив их взаимный порядок. Все свободные области объединяются в один раздел в конце памяти. Новый процесс размещается сразу после занятых разделов, а остаток образует итоговый `HOLE`.
3. Если суммарного объёма свободной памяти недостаточно, вывести `NOT_ENOUGH_MEMORY`.

## Формат ввода

Первая строка содержит `memory_size` и `n` — общий размер памяти и количество исходных разделов (`1 <= n <= 1000`).

Каждая из следующих `n` строк содержит:

```text
id size
```

Здесь `id` — строка длиной не более 31 символа без пробелов, а `size` — положительный размер раздела. Разделы перечислены от начала памяти к концу и в сумме занимают ровно `memory_size`.

Последняя строка содержит `new_id new_size` — идентификатор и положительный размер нового процесса. Идентификатор нового процесса отличен от `HOLE`.

## Формат вывода

При успешном размещении вывести итоговую последовательность разделов от начала памяти к концу. Для каждого раздела на отдельной строке вывести:

```text
id size
```

Итоговый раздел `HOLE` выводится только при ненулевом размере. Если разместить процесс невозможно, вывести единственную строку `NOT_ENOUGH_MEMORY`.

## Пример

Ввод:

```text
1000 6
P1 200
HOLE 100
P2 250
HOLE 150
P3 200
HOLE 100
P4 300
```

Вывод:

```text
P1 200
P2 250
P3 200
P4 300
HOLE 50
```

Ни один исходный свободный раздел не вмещает `P4`, но суммарно свободны 350 единиц. Поэтому занятые разделы перемещаются к началу памяти, после них размещается `P4`, а свободными остаются 50 единиц.
