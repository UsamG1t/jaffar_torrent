# Сегментное распределение памяти

## Условие

В сегментной модели логический адрес состоит из номера сегмента и смещения внутри него. Для каждого сегмента заданы физический базовый адрес `base` и размер `size`.

Таблица содержит ровно 4 сегмента с номерами от 0 до 3. Для каждого запроса нужно проверить логический адрес `(segment, offset)` и, если он корректен, вычислить физический адрес.

Адрес считается некорректным, если `segment >= 4` или `offset >= size`. В этом случае необходимо вывести `SEGMENT_FAULT`. Обратите внимание: проверка строгая, поэтому смещение `offset == size` уже выходит за границу сегмента. Последнее допустимое смещение равно `size - 1` (при ненулевом размере сегмента).

## Принцип решения

Сохраним базы и размеры четырёх сегментов в массиве структур. Для каждого запроса сначала проверим номер сегмента, затем сравним смещение с размером выбранного сегмента. При успешной проверке физический адрес вычисляется по формуле:

`PA = base + offset`.

## Формат ввода

Первые четыре строки содержат по два беззнаковых десятичных числа — `base` и `size` для сегментов 0, 1, 2 и 3 соответственно.

Пятая строка содержит беззнаковое десятичное число `q` — количество запросов. Далее следуют `q` строк, каждая из которых содержит два беззнаковых десятичных числа: `segment` и `offset`.

## Формат вывода

Для каждого запроса выведите на отдельной строке физический адрес в десятичном виде либо строку `SEGMENT_FAULT`, если адрес некорректен.

## Пример

**Ввод:**

```text
1000 256
2000 512
3000 128
4000 64
5
0 0
1 511
2 127
2 128
4 0
```

**Вывод:**

```text
1000
2511
3127
SEGMENT_FAULT
SEGMENT_FAULT
```

В третьем запросе смещение 127 допустимо для сегмента размером 128. В четвёртом запросе `offset == size == 128`, поэтому возникает ошибка сегментации. Пятый запрос некорректен из-за номера сегмента 4.
