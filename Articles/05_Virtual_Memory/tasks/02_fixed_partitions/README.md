# Распределение неперемещаемыми разделами

## Условие

Память разделена на `n` неперемещаемых разделов. Все процессы находятся в одной входной очереди. Разделы обрабатываются по одному в порядке ввода; каждый раздел может получить не более одного процесса.

Для текущего свободного раздела нужно выбрать среди ещё ожидающих процессов **самый большой подходящий**: процесс с максимальным размером, не превышающим размер раздела. Если таких процессов несколько, выбирается ближайший к началу очереди. Выбранный процесс удаляется из очереди и занимает раздел. Если подходящих процессов нет, раздел остаётся пустым.

После размещения процесса свободная часть раздела недоступна другим процессам. Разность между размером раздела и размером размещённого процесса называется **внутренней фрагментацией**: память внутри раздела выделена процессу, но фактически им не используется.

## Принцип алгоритма

Для каждого раздела просматривается массив процессов от первого к последнему. Среди ожидающих процессов, размер которых не больше размера раздела, запоминается процесс с наибольшим размером. При равенстве размеров текущий лучший процесс не заменяется, поэтому сохраняется выбор ближайшего к началу очереди. После обработки раздела выбранный процесс помечается как размещённый. Оставшиеся процессы выводятся в исходном порядке.

## Формат ввода

Первая строка содержит целое число `n` (`1 <= n <= 128`) — количество разделов.

Вторая строка содержит `n` целых неотрицательных чисел — размеры разделов.

Третья строка содержит целое число `m` (`0 <= m <= 256`) — количество процессов.

Далее следуют `m` строк, каждая содержит идентификатор процесса и его размер. Идентификатор — строка без пробелов длиной не более 31 символа, размер — целое неотрицательное число.

## Формат вывода

Для каждого раздела выводится одна строка:

- `PARTITION <i> PROCESS <id>`, если раздел `i` получил процесс `<id>`;
- `PARTITION <i> EMPTY`, если подходящего процесса не нашлось.

Нумерация разделов начинается с 1. В последней строке выводится `WAITING`, после которого через пробел перечисляются идентификаторы оставшихся процессов в исходном порядке. Если ожидающих процессов нет, выводится `WAITING -`.

## Пример

Ввод:

```text
3
100 300 200
4
P1 90
P2 280
P3 180
P4 70
```

Вывод:

```text
PARTITION 1 PROCESS P1
PARTITION 2 PROCESS P2
PARTITION 3 PROCESS P3
WAITING P4
```

В разделе размером 100 после размещения `P1` внутренняя фрагментация равна 10. Для `P2` и `P3` она равна 20 в каждом случае. Процесс `P4` не размещён, потому что свободных разделов больше нет.
