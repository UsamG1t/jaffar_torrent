Что такое jaffar_torrent?
---

Это репозиторий, организованный студентами факультета ВМК МГУ им. М.В.Ломоносова, призванный помочь студентам с изучением операционных систем: как в рамках читаемого на факультете курса, так и просто для общего развития.

Авторы репозитория с большим удовольствием готовы участвовать в обсуждениях, обновлять материалы, получать от сообщества задачи на соответствующие темы.
